# Market Intelligence — окрема версія (MVP)

Це **нова незалежна програма** у GitHub-гілці `market-intelligence-v1`, не редизайн старого торгового термінала. Попередня гілка `redesign-approved-trading-ui` лишається без змін.

## Швидкий запуск на Mac

Найпростіше зробити окреме робоче дерево, не перемикаючи стару програму:

```bash
cd ~/Desktop/ai-trading-assistant
git fetch origin market-intelligence-v1
git worktree add --track -b market-intelligence-v1 ~/Desktop/market-intelligence origin/market-intelligence-v1
cd ~/Desktop/market-intelligence
node market-intelligence/server.mjs
```

Якщо локальна гілка з такою назвою вже існує, використовуй `git worktree add ~/Desktop/market-intelligence market-intelligence-v1`. Адреса програми: http://127.0.0.1:4188/ . Node.js 22+ рекомендовано.

Програма не потребує npm install і не змінює попередній сервер на порті 4177. Для оновлення в окремій папці: `cd ~/Desktop/market-intelligence && git pull --ff-only origin market-intelligence-v1` (перезапусти Node-сервер після оновлення).

## Мета та поточні можливості

- **Можливості:** одна найкраща **свіжа та підтверджена** торговельна пропозиція за даними Bybit Public. Entry, Stop Loss, Take Profit, R:R і короткий опис причин.
- **Спостереження:** ліквідні криптоінструменти без готових умов входу. Не підміняються сигналами.
- **Мої плани:** локально збережені рівні (браузерний localStorage), **не** реальні біржові заявки, не синхронізуються між браузерами.
- **Аналітика:** критерії оцінки й обмеження.
- **Підключення:** форма Demo API Key / Secret та перевірка облікового запису з macOS Keychain.

## Джерела та ринки

На цьому етапі **фактичні сигнали працюють лише для криптовалют** через публічний API Bybit. Акції/ETF, Forex і сировинні активи показані як **ще не підключені**. Не видаємо вигадані котирування або готові плани для недоступних ринків.

Сканер відбирає до 16 найбільш ліквідних USDT perpetual, застосовує чинні правила `scripts/market-scanner.mjs` для чотирьох таймфреймів (15м, 1г, 4г, 1д). Кожна пропозиція перевіряється на актуальність (не старша за 20 хвилин). Сканування відбувається приблизно раз на 10 хвилин під час роботи локального сервера.

Сортування за підтвердженнями, R:R та ліквідністю — **це не ймовірність прибутковості**. Правила можуть помилятися; незалежний довготривалий backtest і paper trading залишаються обов'язковими перед реальними угодами.

## Bybit Demo

1. Створи **окремі ключі Demo** в самому Bybit із правами *read-only*, якщо доступно.
2. Відкрий у новій програмі **Підключення**, введи Key і Secret.
3. Локальний сервер перевірить пару запитом до `https://api-demo.bybit.com/v5/account/wallet-balance`.
4. Після успіху обидва значення зберігаються **лише в macOS Keychain** під сервісами `com.market-intelligence.demo.api-key` та `com.market-intelligence.demo.api-secret`. Ці сервіси не перезаписують ключі старої програми.
5. Програма дозволяє лише **перегляд** Demo-балансу, позицій та ордерів. **Жодних endpoint'ів для створення, редагування чи закриття ордерів немає.**

Ключі **ніколи не вводяться у ChatGPT**, не зберігаються в GitHub, HTML-файлах, браузерному localStorage або репозиторії. Для підключення потрібна саме локальна програма на Mac, не GitHub Pages. З'єднання доступне тільки на 127.0.0.1; сервер перевіряє Host/Origin, використовує CSP та не повертає самі секрети клієнту.

## Перевірки

```bash
node --check market-intelligence/server.mjs
node --check market-intelligence/app.js
node .github/scripts/check-market-intelligence.mjs
```

Smoke test працює без реальних API-ключів та без мережевих запитів до Bybit. Він перевіряє запуск, ізоляцію UI, недоступні ринки, блокування чужих Origin і відсутність API для відкриття угод.

### Що залишилося перед повноцінним продуктом

- Підключити й перевірити постачальників котирувань для акцій, Forex і сировини, включно з ліцензіями та торговими сесіями.
- Провести окрему перевірку точності сигналів, статистичну калібровку та вперед-орієнтоване paper trading.
- Додати перевірку виконуваності ціни входу, спреду, funding, комісій, ковзання і ризику портфеля.
- Реалізувати обмеження API, backoff та відновлення після довгих збоїв.

Це перша **signal-first** версія, а не система з гарантованими торговими сигналами.
